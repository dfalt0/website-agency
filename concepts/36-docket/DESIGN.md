# 36 · Docket — Case-file tabs

**Cue:** legal intake / compliance. A website engagement treated as a matter you open, file and keep in custody.
**Metaphor:** a manila folder on a dark desk. Five staggered tabs are the whole navigation; each tab is a dossier page.

## Layout fingerprint
- Page = desk (dark slate) + ONE folder. No scrolling sections; content swaps by tab (Brief · Build · Host · Care · Terms).
- Folder tabs are staggered along the top edge and the active tab merges into the sheet (no bottom border).
- Each page = left **caption column** (matter number, status stamp, key fields) + right **numbered paragraphs** (1.1, 1.2 …) like a filing.
- Primary CTA lives on the last tab: an intake form that "files" with a rubber-stamp animation.

## Type
- Headings / body: Libre Caslon Text. Fields, docket numbers, stamps: Courier Prime. Tab labels, UI: IBM Plex Sans.
- Uppercase tracking on captions only. Body line length ≤ 62ch.

## Colour
Manila `#E6D9B3`, paper `#FBF8EE`, ink navy `#1B2A41`, stamp red `#B3261E`, accepted green `#2D6A4F`, desk `#23282D`. Tabs darken left → right.

## Motion
Tab switch = 160 ms slide of the sheet content + stamp "thunk" (scale 1.4 → 1, slight rotate). Keyboard: ← → move between tabs. URL hash mirrors tab.

## Do / Don't
- Do: dotted fill-in lines, marginal initials boxes, paper-clip, hole punches.
- Don't: cards-in-a-row, hero banner, gradients, icons.

## Uniqueness check
Only concept where nav = physical folder tabs and body is numbered legal paragraphs.
