# 12 — Spread

**Archetype:** Asymmetric magazine. Four "spreads", each a 12-col grid with a faint center gutter, running heads, and folios.

## Layout architecture
- Each `<article class="spread">` has its own explicit grid placement, so no two spreads share a skeleton.
  1. **Cover:** vertical rotated title on the far-left spine; narrow intro (cols 2–5); two-column body with drop cap (cols 2–6); tall CSS **image well** (cols 7–12) built from stacked shapes, with a mono plate caption beneath.
  2. **Build feature:** 5-col lede text, a 4-col "in numbers" sidebar with hairline left rule, and an oversized **pull quote** that overruns the gutter (cols 5–12).
  3. **Departments:** four uneven columns (4 / 3 / 3 / 2) — headline text, a CSS server-rack plate, a care column, a "standing order" list — plus a solid green quote block.
  4. **Letters:** narrow left headline, form on the right laid out like a ruled table (label column + field column).
- Rules: 3px heavy rule under running heads and the form head; 0.5px hairlines between columns and rows.
- No cards, no centered hero, no CTA band.

## Visual system
Cool gray-blue paper on a darker desk, near-black ink, one deep green accent. Serif display and body lede; sans body; mono for kickers, captions, folios. Square, flat, no shadows beyond a hairline under each spread.

## Note
Magazine contemporary (not broadsheet): big type, white space, sparse color; no newspaper masthead or column-heavy dense text.
