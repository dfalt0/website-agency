# Concept 07 — Practice

## Positioning

**What you are:** A traditionally structured website studio — familiar navigation, clear sections, restrained visuals.

**Promise:** Websites handled like a professional practice.

**Not:** Experimental layouts, bold art-direction spectacles, or “concept site” theatrics.

**Ideal client:** Owners who want a professional site that feels normal and easy to use — not a portfolio piece for designers.

## Voice & language

Professional practice. Formal but human. Navy, paper, quiet confidence.

**Sample lines:**
- Hero: “Websites handled like a professional practice.”
- Sub: “Scoped work, clear timelines, and ongoing care — the way you’d expect any serious practice to operate.”
- CTA: “Schedule an intake”

## Visual system

| Token | Value | Role |
|-------|-------|------|
| Background | `#F8F9FB` | Page ground |
| Ink | `#1A2332` | Primary text |
| Mute | `#5C6778` | Secondary text |
| Line | `#D5DBE4` | Borders |
| Accent | `#1F4B7A` | Buttons / links |
| Soft | `#EEF2F7` | Soft panels |
| Card | `#FFFFFF` | Surfaces |

**Type:** Heading `"Source Serif 4", Georgia, serif` · Body `"Source Sans 3", system-ui, sans-serif`

## Layout architecture

Traditional brochure site:
1. Sticky top nav + primary CTA
2. Centered/left hero with one headline, one sub, two CTAs
3. Three service cards
4. Numbered process steps
5. Three pricing tiles
6. Dark closing band + simple footer

Shared business facts: Build from $4,500 · Hosting $49/mo · Care $199/mo.
