**Rail:** Rail — Custom websites, hosted and kept — an essay. TOC: Build · Host · Care · Contact.

**Title:** A website is not a thing you finish. It’s a thing you keep.
**Lede:** We build custom sites, host them ourselves, and stay with them. Here is how that works, in the order it happens.

## Part one — Build
Most websites are assembled… We start with the sentence the site has to make true. Two directions, not twelve. Code by hand, kept small; you get the repo and design files at launch.

## Part two — Host
We host the sites we build; the people who wrote the code watch it run. Nightly backups kept thirty days, certificates renew themselves, a probe submits your contact form every five minutes.
Fig. 2 — release path with gate.

## Part three — Care
The site that was right in March is wrong by October without anyone touching it. Monthly pass + plain request line: “You write an email; we ship the change.”

If this is how you want your site run, tell us about it. We reply within a business day.
