# Concept 23 — Notebook (Lab Notebook)

## Architecture
One long **ruled notebook page** on a dark desk. A 32px baseline grid drives everything (background rules, line-heights, table rows, margins) so text sits on the ruled lines. A double red margin rule splits the page: **handwritten margin annotations** at left (Caveat, blue pen, tilted, each with an arrow pointing into the entry), **the log** at right. Three punched holes at the binding edge.

The pitch is told as five numbered experiments, each with the same anatomy — *Hypothesis / Method / Observation table / Result* plus a rubber **stamp** (FAILED / PASSED / ONGOING):

- EXP-01 Baseline (the client's existing site, measured; failed)
- EXP-02 Build (custom; passed)
- EXP-03 Hosting (12-month uptime; passed)
- EXP-04 Care (reply time, request-to-live; ongoing)
- PROTOCOL — the price list as a bordered protocol box
- EXP-05 Yours — CTA button + signature lines (Principal investigator / Witnessed by you)

## Positioning
Custom websites + hosting + care as a repeatable, measured process. Cue: lab/science AI batches — hypotheses, controls, results, honesty about failure.

## Voice
Dry, empirical, understated. Say "Hypothesis confirmed" not "amazing results". Margin notes are quick, human, a little wry.

## Visual system
| Token | Value |
|---|---|
| Page | `#F4F9FC` with `#BCD6EC` rules |
| Ink | `#1B2540` |
| Margin red | `#E5484D` |
| Pen blue | `#1F4FD0` (annotations only) |
| Stamp red | `#D62839` |
| Highlighter | `#E6FF5E` |
| Desk | `#2A2F3A` |

**Type:** Special Elite (typewritten log, headings, stamps) · Libre Franklin (body) · Caveat (margin annotations).

## Motion
Hard-offset button press. No scroll effects — it's a page, not an app.

## Do not
Use sans-serif UI chrome, cards, gradients, or rounded corners. Don't centre anything; the stamps are the only rotation besides annotations.
