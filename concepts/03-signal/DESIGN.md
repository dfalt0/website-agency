# Concept 03 — Signal

## Positioning

**What you are:** The broadcast partner for businesses that need to be findable and stay on air — custom site as the studio, hosting as the tower.

**Promise:** We build your channel and keep the signal up. Clear message. Clean transmission. No dead air after launch.

**Not:** Ad-tech. Not “content factory.” Not cyberpunk devops cosplay.

**Ideal client:** Service businesses, clinics, contractors, B2C brands that need a sharp public face and zero patience for downtime.

## Voice & language

| Avoid | Signal speaks like |
|-------|--------------------|
| Fully managed | Always on air |
| Infrastructure | The tower |
| Get started | Go live |
| Monitoring | Signal check |
| Custom development | Studio build |

**Tone:** Direct, energetic, short. Slight radio-booth swagger without slang overload. Words: *broadcast, tower, clear, live, frequency, standby, transmit, dead air.*

**Sample lines:**

- Hero: “Build the channel. We’ll keep you on air.”
- Sub: “Custom websites engineered to speak clearly — hosted on towers we run, watched so you never go dark.”
- CTA: “Go live with us” / “Hear the frequency”
- Status line: `SIGNAL · NOMINAL`

## Visual system

| Token | Value | Role |
|-------|-------|------|
| Studio black | `#111111` | Base |
| Snow | `#FAFAFA` | Light panels |
| Signal yellow | `#F5C518` | Primary CTA / key lines |
| Graphite | `#2A2A2A` | Cards on dark |
| Mute | `#8A8A8A` | Secondary text |

**Type:** Space Grotesk (headings) + Inter or Schibsted Grotesk (body). Occasional all-caps mono for status (`ON AIR`, `STBY`).

**Layout:** Hard edges, bold blocks, yellow underlines. Hero feels like a control room — one big statement, waveform or simple frequency bars as decoration (CSS only).

**Motion:** Snappy 150–200ms. Status pulse on a yellow dot. No soft blur poetry.

## Homepage structure

1. On-air hero + CTAs  
2. Studio / Tower / Watchdesk  
3. “Dead air is expensive” comparison strip  
4. Go-live process  
5. Frequencies (pricing tiers)  
6. Standby CTA

## Differentiation

High-energy, high-contrast opposite of misty forest green. Language is broadcast, not engineering mystique.
